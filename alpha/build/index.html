My Drive

Triggers

  • Click or tap the "My drive" button to open the menu, clicking it a second time closes it
  • Keyboard: Pressing the enter or space bar when your cursor is hovered over the button will do the same thing
  • Hover: Moving the mouse over the "My drive" or "Folder options" starts the hover effect
  • Press: clicking down on the button highlights the button blue and the button enters a pressed state.

Rules

  • The menu is closed by default opening it shows folder one and folder two, toggling the "My drive" button closes them.
  • One item is highlighted by hovering at a time by holding the cursor over the buttons. The menu stays open until the user clicks the button again

Feedback

See

  • On hover the button darkens and a shadow pops up
  • The arrow rotates down 90 degrees to point down when the menu is open
  • The menu fades in using transitions when it opens
  • Each menu item has a round gray hover effect

Hear

  • Nothing the interaction doesn't have any sounds

Feel

  • The cursor changes to a pointer finger when covered over clickable buttons, when the folder buttons are pressed it gives a click-type response but no vibration or

Loops & Modes

  • Loops: The dropdown can be opened and closes a number of times. Each time resets the arrow and the menu to the same starting state.
  • Modes: The button has a closed mode, and an open mode. Hover and keyboard focus are extra states on top of these modes.
